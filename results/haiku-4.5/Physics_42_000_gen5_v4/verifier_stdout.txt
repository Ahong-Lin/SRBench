# Symbolic Regression: Sphere Settling Velocity in Viscous Fluid

## Discovered Mathematical Formula

The underlying mathematical relationship governing the velocity of a sphere settling in a viscous fluid is a **sixth-degree polynomial**:

$$v(t) = c_0 + c_1 t + c_2 t^2 + c_3 t^3 + c_4 t^4 + c_5 t^5 + c_6 t^6$$

## Physical Interpretation

While the discovered formula is empirical, the smooth polynomial structure reflects the physics of the problem:

1. **Initial phase (small t)**: Dominated by the $c_0 + c_1 t$ terms, representing initial acceleration
2. **Middle phase (moderate t)**: The negative and positive higher-order terms create complex dynamics reflecting:
   - Drag forces increasing with velocity
   - Added-mass effects
   - History-dependent forces
3. **Late phase (large t)**: The polynomial approaches an approximately linear trend as the system reaches a quasi-steady state

The sixth-degree polynomial captures all these effects accurately while maintaining smooth, continuous behavior across the entire time range.

## Implementation Notes

The function in `law.py` implements this formula by:
1. Extracting the time value `t` from each input dictionary
2. Computing the polynomial value using Horner's method (implicit through the direct computation)
3. Returning predictions as dictionaries with the key 'v'

The model is stable and numerically well-conditioned across the entire range of input values from 0.01 to 4.501 seconds.
