# LLM-SRBench v7：题目结构、演化机制与量纲说明

更新时间：2026-10-13。

本文保存本次讨论中的当前实现说明，方便随时查阅。对应工作区为 `llm-srbench-v7`，主要参照两批 GPT-5.4 replay。后面的量纲与目标说明包含本次复核后的更精确表述；“建议”不代表代码已经实现。

## 1. 每一代究竟是什么

当前进化的主体是一份“科学模型记录”。每一代都描述同一个科学问题，但允许逐步修改公式、增加输入或增加内部状态。完成演化后，最终模型才被采样、包装成 agent 实际求解的题目。

```text
科学场景 → 初始模型 E0 → E1 → … → E5 → 数据与题目
```

| 内容 | 具体是什么 | 演化时怎样变化 |
|---|---|---|
| 科学场景 | 研究什么现象、有哪些基本条件 | 保持原问题背景 |
| 目标 | 要预测哪个量，如反应速率或加速度 | 当前代码强制保持目标符号；ODE 的目标状态也保持 |
| 输入、状态、参数 | 哪些量变化、哪些量固定 | 可以增加输入或状态，也可以改变已有参数的角色 |
| 数学模型 | 静态公式，或完整 ODE 系统 | 每代修改的核心 |
| 演化说明 | 为什么修改、修改了哪条假设、预期出现什么现象 | 每代记录，形成谱系 |

最终文件中的 `equation.json` 保存最终模型，`lineage.jsonl` 保存 E0 至终代的模型记录，`spec.json` 保存数值实验配置及诊断结果。

## 2. 输入、状态、参数的区别

- **O：输出。**目标输出或目标导数。
- **V：输入。**静态题中逐样本变化的条件，如温度、浓度；ODE 中 V 是时间轴。
- **S：状态。**随时间按方程演化的量，如位置、速度、资源量。
- **P：参数。**一份题目数据中固定的系数，如固定质量、固定反应常数。

公式增加一个参数，不一定意味着题目升维。例如：

$$
F=kx\quad\longrightarrow\quad F=kx+\alpha x^3.
$$

如果 $k,\alpha$ 都固定，agent 看到的仍然是 $x\longrightarrow F$。新参数 $\alpha$ 可以带有物理单位；其角色是 P，并不表示它无量纲。

若进一步考虑温度，并让温度逐样本变化：

$$
F=k_0[1+a(T-T_0)]x+\alpha x^3,
$$

题目才变成 $(x,T)\longrightarrow F$。这里 $a$ 应具有温度倒数的量纲。

## 3. 每一代怎样进化

正常情况下，每代包含两次 LLM 调用，中间有一次程序化的数学形式选择。

### 3.1 第一次 LLM 调用：决定科学上为什么修改

LLM 读取当前模型、原始场景、已有机制和假设，提出一个科学缺口，并选择 operation：

| operation | 科学含义 | 例子 |
|---|---|---|
| `add_term` | 补充父模型遗漏的生成过程 | 加入一种损失、运输或反馈过程 |
| `change_assumption` | 放松已有过程的理想化假设并重新推导 | 线性响应改为饱和响应，瞬时响应改为有限松弛 |

分类依据是科学含义。例如，把线性阻力改为线性加二次阻力，虽然数学上新增了一项，仍可归入 `change_assumption`。`add_term` 也不限定为在表达式末尾增加加法项。

实际 guided 模式由 LLM 选择 operation，并非按 50%/50% 随机选择。

机制计划还会说明：

- 父模型的局限或可被利用的简单结构；
- 子模型预期改变的斜率、曲率、交互、阈值等响应关系；
- 机制的激活条件；
- 可计算的诊断量；
- 怎样恢复父模型；
- 父模型共享一组重新拟合的参数后，是否仍可能解释变化。

这些是待验证的科学声明，不等于已经得到验证。

### 3.2 同时决定自由度变化

| freedom_change | 对模型结构的影响 |
|---|---|
| `none` | 保持输入和状态数量，可以修改响应形式或增加固定系数 |
| `add_input` | 静态题增加一个新条件，如温度 T |
| `parameter_to_input` | 原来固定的 k 变成逐样本提供的 k |
| `add_state` | 增加内部状态 z，同时增加其 RHS 和初值 |
| `parameter_to_state` | 原来固定的 k 变成具有自身演化方程的 k(t) |

operation 与 freedom_change 是两个不同的判断。两种 operation 都可能需要释放自由度。

每代最多释放一个新输入或状态，但可以增加多个固定参数。两批 replay 的上限是静态输入 4 个、ODE 状态 4 个。模型家族保持不变，静态题不会在这条谱系中变成 ODE。

新增 ODE 状态必须有自身方程、有限初值，并影响已有状态；不要求所有新增状态都形成双向反馈。

### 3.3 程序选择兼容形式，第二次 LLM 调用实现子模型

程序从兼容的 ontology 数学形式中加权抽样，包括：

- 相加贡献；
- 状态相关系数；
- 变量耦合；
- 饱和或阈值；
- 乘性调制；
- 竞争过程；
- 嵌套非线性；
- 多时间尺度；
- 辅助状态反馈。

然后 LLM 按科学计划和选中的形式生成子方程、完整 ODE 及演化记录。

现有结构检查通过后，该模型成为下一代的父模型。检查包括目标保持、符号声明、变量角色、ODE 闭合、自由度数量、初值与计划字段一致性等。

ontology 中的 difficulty_level 是配置标签，不是实测难度，也不表示代数增加时就自动选择更难形式。

## 4. 贯穿例子：0917 physics_010

E0 研究弹簧振子的加速度：

$$
\dot x=v,\qquad m\dot v=-kx-dv.
$$

它有两个状态 $x,v$，目标始终是 $\dot v$。

| 代次 | 科学假设如何变化 | 模型结构怎样变化 |
|---|---|---|
| E0 | 线性弹性、线性阻力 | 状态为 x、v |
| E1 | 弹性在较大形变下不再线性 | 回复力改为 $-k(1+\alpha x^2)x$；新增固定参数，仍为两个状态 |
| E2 | 阻力在较大速度下不再线性 | 增加 $-q\lvert v\rvert v$；仍为两个状态 |
| E3 | 支撑形变不能瞬时跟上位移 | 新增 z，令 $\dot z=(x-z)/\tau$；回复力改为由 z 决定 |
| E4 | 松弛速度受形变历史影响 | 新增 c，令 $\dot c=\gamma(z^2-c)$，并由 c 调节 z 的松弛速度 |
| E5 | 三次硬化发生饱和 | 把 $\alpha z^2$ 改为 $\alpha z^2/(1+sz^2)$；保持四个状态 |

最终系统为：

$$
\begin{aligned}
\dot x&=v,\\
\dot v&=-\frac{k}{m}\left(1+\frac{\alpha z^2}{1+sz^2}\right)z
        -\frac{d}{m}v-\frac{q}{m}\lvert v\rvert v,\\
\dot z&=\frac{1+\beta c}{\tau}(x-z),\\
\dot c&=\gamma(z^2-c).
\end{aligned}
$$

这里的字母是便于阅读的简称；$q$ 是非线性阻力系数，$s$ 是弹性饱和系数，$\beta$ 是 conditioning_strain_coefficient。

这条谱系可以概括为：

> 两状态线性振子 → 非线性弹性 → 非线性阻力 → 形变记忆 → 松弛速率的历史依赖 → 弹性饱和。

其量纲可以一致赋为：

$$
[x]=[z]=L,\quad[v]=L/T,\quad[c]=L^2,
$$

$$
[k]=M/T^2,\quad[d]=M/T,\quad[q]=M/L,
$$

$$
[\alpha]=[s]=[\beta]=L^{-2},\quad[\tau]=T,\quad[\gamma]=T^{-1}.
$$

因此该题不能因为包含 $1+\beta c$ 或 $z^2-c$ 就被判为量纲错误。它们明确允许带量纲的系数和状态。这里是“可赋予一致量纲”，不代表现有 pipeline 已经执行过量纲检查，也不代表被动性等科学性质已被证明。

## 5. 完整系统与 agent 实际求解的题目

生成器积分完整 ODE，得到轨迹，并向 agent 提供：

$$
(t,x,v,z,c)\longrightarrow\dot v.
$$

当前 agent 只需要恢复指定的加速度关系，不需要提交另外三条状态方程。

因此，应分别记录：

- **系统状态数：4 个。**即 x、v、z、c。
- **题面输入特征数：5 个。**包含时间 t。
- **目标公式直接依赖的状态数：2 个。**即 z、v。

E4 增加 c 后，系统运动会改变，但给定相同 z、v，加速度公式没有改变。c 影响轨迹，并不因此成为目标公式的显式自变量。

这不表示应让用户重新选择目标。当前目标已经固定。应做的是自动判断本代属于：

1. 改变当前被评分的目标映射；
2. 改变辅助动力学或数据所处区域；
3. 在现有实验条件下没有明显可辨识影响。

若未来需要评价整套系统恢复，可以另设任务类型；当前题目的目标不需要被悄悄更换。

## 6. 演化之后：DataSpec、数据、包装与评分

两批 GPT-5.4 replay 复用了旧场景与 E0，再完成 5 代演化和 DataSpec；不是重新生成全部基础问题。当前主流程到设定代数就停止，novelty 标为 NOT_EVALUATED，没有 solver 难度反馈驱动的自动继续演化。

终代完成后，DataSpec 选择参数、范围和数值实验配置：

- 静态模型直接计算输出；
- ODE 积分获得轨迹，在轨迹状态上代入目标 RHS 计算标签；
- 不添加观测噪声；
- 保存数值有效性、诊断量覆盖、目标方差、父模型吸收性等报告。

正式包装会从同一 spec 重新生成训练／测试数据，默认 4,500／500 点：

| 类型 | 当前隐藏划分 |
|---|---|
| 一维静态 | 采样坐标前 90% 训练，后 10% 测试；log 轴按 log 坐标 |
| 多维静态 | 联合右上角、体积 10% 的区域作测试，其余区域训练 |
| ODE | 同一初值轨迹的时间末段作测试 |

当前标准题面主要提供数据、变量角色和目标类型，没有完整传递生成时的科学场景与单位。当前评分主要评价 law.py 的数值预测，不自动评价整个 ODE 的结构恢复。

原始 R² 不截断、没有 −1 下界；执行失败也可能得到 reward=−1，因此需要结合状态字段解释分数。

## 7. 为什么关注目标，仍可能出现量纲偏移

“保持目标”与“验证量纲”是不同的程序约束。

当前已经强制：

- target_symbol 不变；
- ODE 的 time_symbol、target_state 不变；
- expression 等于目标状态的 RHS；
- DataSpec 继承完整 ODE 和初值。

这些保证模型仍然回答同一个目标。例如目标一直叫 dv_dt，却仍可能把错误量纲的项加入它的 RHS。

当前尚没有独立的结构化单位字段，也没有对每个表达式节点传播和比较量纲。P/V/S/O 只表示数学角色，不表示单位。Python 对浮点数做加减时也不会检查它们代表米、秒还是浓度。

量纲偏移常发生在：

- 把有量纲量直接放入 $1+\cdots$、指数或饱和因子；
- 复用一个系数，却让它承担不兼容的尺度；
- 参数成为状态后，忘记新增导数需要除以时间；
- 在浓度状态和比例状态之间复用同一通量；
- 给系数写了“无量纲”，实际公式却要求它带单位。

这些问题与是否固定了目标符号相互独立。

## 8. 量纲审计必须允许系数带单位

判断原则是：**先尊重已有物理量定义与单位制，对未声明单位的系数尝试反推，再检查所有出现位置能否同时满足。**

例如：

$$
F=k(1+a x^2)x,\qquad[x]=L.
$$

只要 $[k]=M/T^2$、$[a]=L^{-2}$，公式就自洽。不能因为看到 $1+a x^2$ 就判错；也不能因为 a 的数值是 1，就认定 a 无量纲。

应区分四种结果：

| 类别 | 含义 |
|---|---|
| 已声明或可推导为一致 | 存在一套与物理含义相容的单位赋值；可以补全元数据 |
| 单位声明与公式冲突 | 例如文件明确称系数无量纲，但公式要求它带单位；可能通过修正声明解决 |
| 联合方程冲突 | 同一量在多个位置被要求具有不同量纲；保持物理含义时不能只修改一个系数的单位解决 |
| 信息不足 | 归一化、自然单位或参考尺度交代不完整；保留待澄清，不直接判错 |

未知单位不一定能唯一确定。只要存在一致赋值，就不能因不唯一而判错；但也不应据此声称物理解释已完整验证。

### 8.1 可通过修正系数单位使现有公式自洽的案例

**0917 biology_001**

当前含：

$$
1+\gamma_{\rm crowd}\gamma_{\rm adapt}D.
$$

记录明确称 gamma_crowd 无量纲，而 gamma_adapt × D 为时间倒数。按现有声明冲突。如果将 gamma_crowd 正确解释为时间尺度，现有表达式可以量纲闭合，但需同步修改科学描述、单位及换算规则。

**0917 biology_018**

当前含：

$$
K_i+\beta I.
$$

记录给 $[K_i]=[I]=C$，$[\beta]=C^{-1}$，因此成为浓度与无量纲数相加。如果将 beta 改为无量纲，现有公式可量纲闭合，但原先关于有效浓度 $I/(1+\beta I)$ 的推导需要重新核对。

此题 Ki 是变化输入，beta 是固定参数，不能笼统把 Ki 吸收到一个跨全部条件共享的固定 beta 中。

**0921 physics_029**

模型含 $1+b\dot\gamma^{0.8}$。给予 b 时间的 0.8 次方量纲即可自洽；当前冲突来自文件明确将 b 描述为无量纲。

这些属于“当前单位说明与公式不一致”，不是“无论怎样给系数赋单位，公式都无法成立”。

### 8.2 不能只靠重新给系数赋单位解决的案例

**0921 physics_030**

令 $w$ 表示 stiffness_overshoot_state。已有完整系统同时规定：

$$
\dot u=-gk\tanh(kh)q\eta,\qquad\dot q=w,
$$

$$
\dot w=\frac{(1+\alpha\eta^2-q)/\tau-w}{\tau}.
$$

变量说明给 eta 为米、u 为米／秒、g 为米／秒²，因此这些方程联合要求：

$$
[q]=1,\qquad[w]=T^{-1},\qquad[\alpha]=L^{-2}.
$$

但目标公式是：

$$
\dot\eta=\frac{u}{1+\alpha\eta^2(q+w^2)}.
$$

$q+w^2$ 将无量纲量与时间倒数平方相加。给 alpha 改单位无法同时满足两项与其他状态方程。要保留现有物理含义，需要修改模型或明确加入参考尺度；例如对 w 做时间尺度归一化可以消除这一局部冲突，但并非唯一或已经选定的科学修复。

**0921 biology_010**

同一缓冲通量 J 同时用于：

$$
\dot C=\cdots-J,\qquad\dot B=J.
$$

当前 C 是浓度、B 是占据比例。因此 J 同时被要求为浓度／时间和时间倒数。单独给 J 内部系数补单位不能同时满足；需要补缓冲浓度尺度，或明确重定义并无量纲化 C。

### 8.3 已注意到的带量纲系数与自然单位正例

- 0917 physics_010：c 可为长度平方，多个修正系数可为长度倒数平方，整体可自洽。
- 0921 physics_026：beta_elastic 明确为 s²/m²，恰好抵消 omega² × R² 的量纲。
- 0921 physics_013：spec 明确核电荷半径尺度为 GeV⁻¹，与 Q² 的 GeV² 抵消，不能强行按米判断。
- 0917 physics_012、0921 physics_010 等存在归一化说明但参考尺度不完整的情况，前次审计将其单列为待澄清，没有直接按 SI 判错。

前次“至少 14 道存在冲突”的准确含义，是人工审查中发现至少 14 道与当前单位声明或明确实验单位设定不一致。这个数字混合了可修正的单位声明问题和更强的方程约束冲突，不能解释为“14 道公式都无法赋予任何合理单位”，也不是自动证明后的全量通过率。

## 9. 最小修改如何对应现有流程

保留当前已经确定的目标，补齐以下链条即可：

1. **E0：**建立单位及归一化说明，未知系数单位允许推导。
2. **机制规划：**继承目标、变量含义和已有单位，声明新符号的物理意义。
3. **公式实现后：**联合检查目标表达式和全部 ODE RHS；将声明冲突、方程冲突、信息不足分开。
4. **进入下一代前：**判断变化作用于目标函数还是辅助动力学；保留科学合理的变化，但准确记录它对当前评分对象的贡献。
5. **DataSpec：**参数数值绑定单位，采样范围绑定物理条件，并验证换单位后预测不变。
6. **包装与评测：**依据既定任务公开适当的科学信息，保持目标不变；若新增完整系统恢复任务，作为明确的新评测设置。

现有父模型吸收性诊断还需修复参数被当作数据列而未进入优化的问题。当前两批各 59 道 refit=not_run，另各 1 道诊断错误，不能将报告存在理解为父参数已重拟合。
