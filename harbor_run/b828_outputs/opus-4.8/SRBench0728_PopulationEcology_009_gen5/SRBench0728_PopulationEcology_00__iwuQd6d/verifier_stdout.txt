# Discovered Law for `dN_dt`

## Summary

The data describe a **damped-oscillatory population model with delayed crowding
feedback**. The instantaneous right-hand side is an explicit, autonomous
function of the current density `N` and the current crowding load `C`
(`crowding_load`):

```
dN/dt = N * ( a + b*N + c*C + d*C^2 )
```

with fitted constants

| parameter | value            | role                                |
|-----------|------------------|-------------------------------------|
| `a`       |  5.12297058e-01  | baseline per-capita growth          |
| `b`       |  2.16994975e-05  | density self-term (× N)             |
| `c`       | -7.61344523e-04  | crowding pressure (× C)             |
| `d`       |  1.89071570e-07  | crowding curvature (× C²)           |

Equivalently, the per-capita growth rate `g = a + b*N + c*C + d*C^2` is positive
when the crowding load is low and turns negative once `C` grows past the
carrying capacity, producing the observed overshoot-and-decay dynamics.

## How the system works

`crowding_load` is not an independent driver — it is a **smoothed / delayed
memory of the population itself**. Numerically differentiating the training
trajectory reveals an essentially exact relation:

```
dC/dt = 0.2 * (N - C)        (residual rmse ≈ 8e-4, i.e. exact)
```

So `C` is a first-order low-pass filter of `N` with time constant τ = 5. This
delayed feedback is what turns simple logistic growth into a **damped
oscillation**: `N` overshoots because the crowding signal `C` lags behind the
true density, then the system spirals into the equilibrium.

**Equilibrium.** A fixed point requires `dC/dt = 0 ⇒ N = C`, and `dN/dt = 0 ⇒
g = 0`. Solving `a + (b+c)x + d x² = 0` gives `N* = C* ≈ 899`, matching the
value the trajectory settles to (~890–900). Linearizing about this point gives
a complex eigenvalue pair with oscillation period ≈ 23 time units, which agrees
with the peak-to-peak spacing seen in the data (peaks near t ≈ 10 and t ≈ 33).

## Methodology

1. **Identified the second state equation.** `np.gradient` of `C` against `t`
   is fit exactly by `0.2*(N - C)`, confirming `C` is a delayed density and that
   the system is a 2-D autonomous ODE in `(N, C)`.
2. **Confirmed `dN_dt` matches the numerical derivative of `N`** (corr = 1.0),
   so the target is the genuine RHS of the `N` equation.
3. **Searched functional forms for `dN/dt = f(N, C)`.** Working with the
   per-capita rate `R = dN_dt / N`:
   - Pure delayed-logistic `R = r(1 - C/K)` captures the correct sign,
     equilibrium and oscillation period but leaves structured residuals
     (rmse ≈ 18.9).
   - Adding a density term and a crowding-curvature term
     (`R = a + b*N + c*C + d*C²`) removes most of the residual. The `N` term is
     required: near equilibrium the local Jacobian depends on `N`, so a
     `C`-only law extrapolates poorly.
4. **Rejected explicit time dependence.** Adding `t`-terms lowered the training
   error slightly but *increased* the held-out (later-time) error from ~4.0 to
   ~6.7 — `t` only overfits the initial transient. The final law is therefore
   autonomous, which is what keeps it valid on the right-hand extrapolation
   segment.
5. **Fit `a, b, c, d`** by linear least squares (features `N, N², N·C, N·C²`)
   on the full training set.

## Fit quality

- Full training set: RMSE ≈ 10.6, R² ≈ 0.984 (target std ≈ 84.9).
- Forward time-split validation (train `t < 48`, test `t ≥ 50`): RMSE ≈ 3.97,
  comparable to the achievable in-sample floor in that near-equilibrium regime
  where `dN_dt` values are small (std ≈ 4). The equilibrium and local dynamics
  are reproduced correctly, so predictions remain well-behaved as the
  oscillation continues to decay beyond the observed window.

## Final law

```python
             + 2.16994975e-05 * N
             - 7.61344523e-04 * crowding_load
             + 1.89071570e-07 * crowding_load**2)
```
