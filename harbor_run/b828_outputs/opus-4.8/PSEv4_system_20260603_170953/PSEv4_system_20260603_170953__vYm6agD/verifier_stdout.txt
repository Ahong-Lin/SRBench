"""Discovered instantaneous acceleration law.

The data are generated by a driven, damped, nonlinear (hardening) oscillator:

    dv/dt = A*sin(w*t)  -  c*sin(v)  -  R(x)

where
  * A*sin(w*t)  is a sinusoidal external drive with w = 1,
  * c*sin(v)    is a weak nonlinear (velocity) damping term,
  * R(x)        is an odd, hardening restoring force, represented by the
                fitted odd polynomial  R(x) = a1*x + a3*x^3 + ... + a9*x^9.

All parameters were inferred from the training data by least squares.
Each row is mapped independently; no state is carried between calls.
"""

import math

# Drive: A*sin(w*t), w = 1
A = 1.1975813217200704
W = 1.0

# Nonlinear damping: -D*sin(v)
D = 0.2993998510377894

# Hardening restoring force R(x) = sum a_k x^k (odd powers)
X_POWERS = (1, 3, 5, 7, 9)
X_COEFFS = (
    -0.7919713962960969,
    -0.17236582340935613,
    -0.5685745735753579,
    0.19803738297226345,
    -0.026031813707994542,
)


def _dv_dt(t: float, x: float, v: float) -> float:
    drive = A * math.sin(W * t)
    damping = -D * math.sin(v)
    restoring = 0.0
    for k, a in zip(X_POWERS, X_COEFFS):
        restoring += a * x ** k
    return drive + damping + restoring


def law(input_data: list[dict[str, float]]) -> list[dict[str, float]]:
    out = []
    for row in input_data:
        t = float(row["t"])
        x = float(row["x"])
        v = float(row["v"])
        out.append({"dv_dt": _dv_dt(t, x, v)})
    return out

# Discovered law for `dv_dt`

## Summary

The dataset is generated by a **driven, damped, nonlinear (hardening) oscillator**.
The instantaneous acceleration is an explicit, additive pointwise function of the
declared variables:

```
dv_dt = A·sin(t)  −  c·sin(v)  −  R(x)
```

with a hardening restoring force

```
R(x) = a1·x + a3·x³ + a5·x⁵ + a7·x⁷ + a9·x⁹   (odd polynomial)
```

## Parameters (fit by least squares on the training data)

| term | meaning | value |
|------|---------|-------|
| `A`  | drive amplitude | `1.19758` |
| `ω`  | drive angular frequency | `1.0` |
| `c`  | damping strength (`−c·sin(v)`) | `0.29940` |
| `a1` | linear stiffness | `−0.79197` |
| `a3` | x³ coefficient | `−0.17237` |
| `a5` | x⁵ coefficient | `−0.56857` |
| `a7` | x⁷ coefficient | `+0.19804` |
| `a9` | x⁹ coefficient | `−0.02603` |

## How the form was found

1. **Correlation / linear screen.** `dv_dt` is strongly anti-correlated with `x`
   (r ≈ −0.86) and shows a clean sinusoidal dependence on `t`. A regression on
   `{sin t, cos t, x, v}` immediately isolates a drive term `≈1.19·sin(t)`
   (the `cos t` coefficient and any phase are ~0, and the fitted frequency is
   `ω = 1.000`), a restoring term in `x`, and a damping term in `v`.

2. **Additivity confirmed.** A flexible fit `A·sin(t) + f(x) + g(v)` (with `f`, `g`
   odd polynomials) drives R² to ≈0.99999 and leaves residuals with **no**
   remaining correlation with `t` or `v`. All even-power and cross terms
   (`x²`, `x·v`, `x²·v`, `x·sin t`, …) fit to ~0, so the right-hand side is a
   sum of three independent single-variable functions and the system is
   deterministic (essentially noise-free: residuals vary smoothly with `x`).

3. **Damping identified as `−c·sin(v)`.** The odd-power Taylor coefficients of the
   velocity term come out as `(−0.2994, +0.0506, −0.00248, …)`, i.e. in the exact
   ratio `−c·(1, −1/6, +1/120, …)` — the series of `−c·sin(v)` with `c ≈ 0.30`.

4. **Restoring force `R(x)`.** `R(x) = dv_dt − 1.2·sin(t) + 0.3·sin(v)` is an odd,
   monotonic, *hardening* function (its effective stiffness `R/x` grows from
   ≈0.8 near the origin to ≈2.8 at `|x|≈1.6`). No compact two/three-parameter
   closed form (sinh, x·cosh, tan, rational, power-law) reproduces it to the
   noise floor, so it is represented by its odd-polynomial expansion up to `x⁹`,
   which is monotonic over the full data range (and beyond, on `[−2, 2]`) and is
   the parsimonious explicit description of the observed spring.

## Fit quality

On the full training set:

- **R² = 0.99998**
- RMS error = **0.0056**
- Max absolute error = **0.018**

The model generalizes (train/test RMS are equal under a time-extrapolation split),
confirming the coefficients are not an artifact of trajectory collinearity.

## Notes / limitations

- `ω = 1` and the damping `c ≈ 0.30` are clean; the drive amplitude `A ≈ 1.198`
  is very close to `1.2`.
- The restoring force is genuinely nonlinear (a cubic-only Duffing spring is
  insufficient: it leaves RMS ≈ 0.037). The `x⁷`/`x⁹` terms are the truncated
  Taylor tail of a smooth hardening spring, so the polynomial should be used as
  an interpolant within the observed range `|x| ≲ 1.75`.
- Each prediction depends only on `(t, x, v)` for that row — no state, ordering,
  differentiation, or data access is used.
